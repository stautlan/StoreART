# АртЛавка — магазин товаров для творчества и художественных принадлежностей

**АртЛавка** — удобное приложение для художников, дизайнеров и всех, кто увлечён творчеством. В одном месте собрано всё необходимое для рисования, лепки, скетчинга и декора — от базовых расходников до профессиональных материалов.

## Основные возможности

* **Актуальный прайс и каталог** — удобный поиск по категориям (краски, кисти, холсты, бумага, графические материалы) с фильтрами по брендам, ценам и наличию.
* **Умная корзина** — быстрое добавление товаров, автоматический расчёт стоимости с учётом скидок и сохранение выбранных позиций.
* **Онлайн-оплата** — безопасная и мгновенная оплата заказа банковской картой или через СБП прямо в приложении.
* **Курьерская доставка** — выбор удобного интервала доставки до двери и отслеживание статуса заказа в реальном времени.
